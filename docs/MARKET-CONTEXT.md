# Market Context for Scalping Backtests\n\n`session.ts` classifies candle timestamps using explicit UTC windows:\n- Asia: 00:00–08:00 UTC\n- London: 08:00–13:00 UTC\n- New York: 13:00–21:00 UTC\n- Outside those windows: Unknown\n\nThe windows are deliberately UTC-based and do not silently apply local DST rules. Broker-specific session calendars can be supplied later.\n\nPaper trades now retain the detected session and entry ATR. Execution analysis exposes spread/ATR plus entry and exit slippage/ATR ratios.\n\nThese metrics are diagnostic. They describe the execution context of historical simulations and do not predict future market behavior.
