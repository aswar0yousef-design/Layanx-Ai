# تشغيل LayanX على Windows

## التشغيل لأول مرة

1. حمّل المستودع (Code ← Download ZIP) وفك الضغط في مجلد مثل `C:\LayanX`. تجنّب مجلد التنزيلات المؤقت.
2. انقر نقراً مزدوجاً على **LayanX.cmd**.
3. ستظهر نافذة سوداء تطلب الموافقة فقط على ما ينقص:
   - Node.js 22 أو أحدث (يُثبَّت عبر winget إن وافقت)
   - Ollama لتشغيل النماذج على جهازك
   - نموذج مبدئي يناسب ذاكرة جهازك (3B لأقل من 12 غيغابايت، 7B حتى 24، و14B لما فوق)
4. يُفتح المتصفح على صفحة **LayanX على هذا الجهاز**، ويُنشأ اختصار LayanX على سطح المكتب.

بعد ذلك يكفي النقر على الاختصار. للإيقاف: زر **إيقاف LayanX** في الصفحة، أو **LayanX-Stop.cmd**.

## أين تُحفظ بياناتك

كل شيء يخص تثبيتك في `%LOCALAPPDATA%\LayanX` وليس داخل مجلد المشروع:

- `secrets.dpapi`: مفاتيح الخدمات مشفّرة بـ Windows DPAPI لحسابك فقط. لو نُسخ الملف لجهاز آخر أو فتحه مستخدم آخر فلا يمكن فكّه.
- `store\`: بيانات المتجر والوسائط والمحتوى.
- `devices.json`: الهواتف المربوطة (بصمات المفاتيح فقط، وليس المفاتيح نفسها).
- `logs\layanx.log`: السجل.

تحديث المشروع من GitHub لا يلمس هذا المجلد. وإذا حمّل شخص آخر نفس المستودع، فله مجلده ومفاتيحه ورموز ربطه الخاصة، ولا يستطيع هاتفه الوصول لجهازك.

## إضافة المفاتيح

من الصفحة: **مفاتيح الخدمات** ← اسم المفتاح والقيمة ← **حفظ المفتاح** ← **إعادة التشغيل**.

إن كانت مفاتيحك في ملف `.env` حالياً، انقلها كلها مرة واحدة:

```
npm run secrets -- import .env
```

ينقل الأمر القيم السرية إلى الخزنة ويفرغها من الملف، ويترك الإعدادات العادية كما هي.

## النماذج المحلية

لا تحتاج إلى تحديد نموذج. LayanX يقرأ ما هو مثبت في Ollama وقدرات كل نموذج (الأدوات، الرؤية، التفكير، التضمين) ويختار لكل مهمة الأنسب لذاكرة جهازك. إن ثبّت نموذجاً جديداً (`ollama pull ...`) اضغط **إعادة فحص النماذج** ثم **إعادة التشغيل**. يمكنك تثبيت نموذج معيّن لمهمة من القائمة بجانبها، وإن حُذف لاحقاً يعود الاختيار تلقائياً.

## ربط الهاتف

1. فعّل **السماح للهاتف بالاتصال عبر شبكة Wi-Fi نفسها** ثم **إعادة التشغيل**.
2. سيسألك جدار حماية Windows عن السماح لـ Node.js على **الشبكات الخاصة**: وافق (ولا تختر الشبكات العامة).
3. اضغط **إنشاء رمز ربط** وأدخل العنوان والرمز في تطبيق الهاتف خلال 5 دقائق.
4. لإلغاء هاتف: **إلغاء الربط** بجانب اسمه.

الاتصال داخل الشبكة المنزلية غير مشفّر (HTTP). لا تفعّله على شبكة مقهى أو فندق. للوصول من خارج المنزل استخدم شبكة خاصة مثل Tailscale بدل فتح المنفذ على الإنترنت.

## حل المشكلات

| ما تراه | السبب والحل |
|---|---|
| "Port 3000 is used by another program" | برنامج آخر يستخدم المنفذ. أغلقه، أو عيّن متغير البيئة `LAYANX_PUBLIC_PORT=3300`. |
| الصفحة تقول "افتح LayanX من الاختصار" | فتحت العنوان يدوياً. افتحه من الاختصار ليُنشأ رابط دخول لمرة واحدة. |
| "Ollama غير متاح" | شغّل تطبيق Ollama أو ثبّته: `winget install Ollama.Ollama` ثم **إعادة فحص النماذج**. |
| "DPAPI operation failed" | شغّل `npm run secrets -- selftest`. إن فشل، أرسل السجل؛ لا تغيّر إلى الوضع الأضعف إلا مؤقتاً: `LAYANX_SECRET_BACKEND=file`. |
| Windows SmartScreen يحذّر من LayanX.cmd | لأن الملف من الإنترنت. اختر "مزيد من المعلومات" ثم "تشغيل على أي حال"، أو انقر بالزر الأيمن ← خصائص ← إلغاء الحظر. |
| لم يبدأ خلال دقيقتين | افتح `%LOCALAPPDATA%\LayanX\logs\layanx.log`. سطر "runtime failed" يحدد السبب. |
