# Data Quality and Multi-Window Walk-Forward\n\n`candle-quality.ts` checks historical candle integrity before walk-forward evaluation.\n\nChecks include:\n- invalid OHLC ranges\n- duplicate timestamps\n- non-monotonic timestamps\n- optional candle gaps larger than the expected interval\n\n`walk-forward-windows.ts` creates chronological train/test windows.\n`multi-window-walk-forward.ts` runs the same paper engine on each window and aggregates only the out-of-sample test analyses.\n\nThe current implementation does not optimize parameters. It creates a clean framework for future training/selection while keeping out-of-sample evaluation separate.\n\nHistorical performance remains diagnostic and does not guarantee future trading results.
