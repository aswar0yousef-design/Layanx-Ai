# تشغيل LayanX والتحقق منه وربط الحسابات

## 1. التشغيل

1. تأكد أن Ollama يعمل.
2. انقر نقرا مزدوجا على `LayanX.cmd` في مجلد المشروع. يفتح صفحة الإعداد.
3. للإيقاف: `LayanX-Stop.cmd`.

### التشغيل الدائم

لتشغيل LayanX تلقائياً عند كل تسجيل دخول، وإعادته إن توقف:

```bash
powershell -ExecutionPolicy Bypass -File scripts/windows/install-autostart.ps1
```

| الحالة | ما يحدث |
|---|---|
| تسجيل الدخول إلى Windows | المهمة المجدولة `LayanX` تشغّل المراقب `scripts/windows/watchdog.ps1`، وهو يشغّل LayanX |
| توقف LayanX أو انهار | المراقب يفحص كل 30 ثانية ويعيد تشغيله؛ عند تكرار الفشل ينتظر أطول حتى 10 دقائق |
| `LayanX-Stop.cmd` | إيقاف مقصود: يبقى متوقفاً حتى تشغّله بنفسك بـ `LayanX.cmd` |
| إزالة التشغيل الدائم | `install-autostart.ps1 -Remove` |

مهمة للمستخدم لا خدمة Windows، لأن LayanX يتحكم بسطح المكتب والشاشة والميكروفون، والخدمة تعمل في جلسة لا تصل إليها. لا يحتاج صلاحيات مدير. في التشغيل التلقائي لا يُثبَّت ولا يُنزَّل أي برنامج أو نموذج بلا موافقتك. السجل في `%LOCALAPPDATA%\LayanX\logs\watchdog.log`.

**مُختبر على جهاز المالك (2026-11-11):** التثبيت بدأ LayanX؛ قتله بالقوة أعاده المراقب خلال 11 ثانية؛ الإيقاف المقصود بقي أكثر من دقيقة دون إعادة؛ التشغيل اليدوي أعاد المراقبة. **لم يُختبر بعد:** إعادة تشغيل الجهاز وتسجيل الدخول الفعلي.

| العنوان | الاستخدام |
|---|---|
| `http://127.0.0.1:3000/setup` | الإعداد والنماذج وربط الهاتف |
| `http://127.0.0.1:3000/` | لوحة التحكم والمهام والموافقات |
| `http://127.0.0.1:3000/voice` | المساعد بالصوت والكتابة |
| `http://127.0.0.1:3100/flow` | منشئ تدفقات واتساب وتيليجرام |

السجل في `%LOCALAPPDATA%\LayanX\logs\layanx.log`.

كرت الشاشة يتسع لنموذج واحد. لا تشغل LayanX أثناء أي قياس من الأقسام التالية، ولا تشغل قياسين معا.

## 2. التحقق بدون أي حساب

### فحص سريع

```bash
npm run doctor
```

```bash
npm run release:check
```

الأول يفحص الجهاز والخدمات. الثاني يفحص الأمان والأنواع وكل الاختبارات الآلية، ويجب أن ينتهي دون فشل.

### جرب بنفسك من المحادثة

افتح `/voice` أو لوحة التحكم واكتب:

| اكتب | النتيجة الصحيحة |
|---|---|
| ابن لي برنامج سطر أوامر يحول الأرقام إلى أرقام رومانية | مجلد مشروع فيه برنامج واختبارات، وتشغيله يعطي `XIV` للرقم 14 |
| ابن لي صفحة هبوط لمتجر قهوة تناسب الجوال | تفتح الصفحة، ولا يظهر تمرير أفقي على عرض الهاتف |
| ابن لي تطبيق مهام فيه إضافة وحذف | بعد إعادة تحميل الصفحة تبقى المهام المحفوظة |
| أصلح المشروع الموجود في المجلد `<المسار>` | يصلح نسخة معزولة، ويعرض الأدلة قبل التسليم |
| اعرض ما فعلته اليوم | تقرير يطابق المهام الظاهرة في لوحة التحكم |

عند مستوى الثقة `supervised` تنتظر الإجراءات المحمية موافقتك في لوحة التحكم. هذا سلوك مقصود، وليس تعطلا.

### القياس المستقل

كل أمر يعمل في مجلدات مؤقتة، ويحكم عليه كود منفصل عن النظام الذي يبني المشروع.

| ما يقيسه | الأمر |
|---|---|
| بناء ستة أنواع من المشاريع | `npx tsx scripts/outcome-build-types-acceptance.ts --runs 3` |
| بناء تطبيق مهام كامل | `npx tsx scripts/outcome-batch-acceptance.ts --runs=5` |
| إصلاح مشاريع Node موجودة | `npx tsx scripts/outcome-node-repair-acceptance.ts --runs 3` |
| مراجعة الكود | `npx tsx scripts/outcome-review-acceptance.ts --runs 3` |
| استمرار العمل بعد إعادة التشغيل | `npx tsx scripts/outcome-restart-acceptance.ts` |
| النجاة من تعطل مفاجئ | `npx tsx scripts/outcome-crash-acceptance.ts` |
| اكتشاف التوقف بلا تقدم | `npx tsx scripts/outcome-stall-acceptance.ts` |
| أثر الأفعال في المتصفح | `npx tsx scripts/outcome-browser-effect-acceptance.ts` |
| أثر الأفعال على سطح المكتب | `npx tsx scripts/outcome-desktop-effect-acceptance.ts` |
| لوحة التحكم | `npx tsx scripts/outcome-dashboard-acceptance.ts` |
| دمج عمل عدة نماذج | `npx tsx scripts/outcome-merge-acceptance.ts` |
| التطوير الذاتي | `npx tsx scripts/outcome-self-dev-acceptance.ts` |
| دورة التحسين | `npx tsx scripts/outcome-improve-acceptance.ts --cases csv,wordcount --runs 3` |

## 3. إدخال الحسابات

أدخل كل قيمة بهذا الأمر، وهو يطلبها دون إظهارها، ويحفظها مشفرة خارج مجلد المشروع:

```bash
npm run secrets -- set اسم_القيمة
```

لرؤية الأسماء فقط، دون القيم:

```bash
npm run secrets -- list
```

بعد الإدخال أعد تشغيل LayanX. ابدأ كل منصة باختبار قراءة فقط.

### واتساب API الرسمي

تحتاج تطبيقا في Meta for Developers، ورقم واتساب للأعمال، وعنوان HTTPS عاما يصل إلى جهازك.

| الاسم | القيمة |
|---|---|
| `LAYANX_WHATSAPP_ENABLED` | `true` |
| `LAYANX_WHATSAPP_ACCESS_TOKEN` | رمز الوصول من Meta |
| `LAYANX_WHATSAPP_PHONE_NUMBER_ID` | معرف الرقم |
| `LAYANX_WHATSAPP_VERIFY_TOKEN` | نص طويل تختاره أنت |
| `LAYANX_WHATSAPP_APP_SECRET` | App Secret |
| `LAYANX_WHATSAPP_OWNER_IDS` | رقمك بالصيغة الدولية بلا `+` |

عنوان الويب هوك في Meta هو `https://نطاقك/v1/channels/whatsapp/webhook`.

**الاختبار:** أرسل رسالة من رقمك إلى رقم الأعمال، ويجب أن يصل الرد في المحادثة نفسها.

### واتساب عبر QR

هذا الطريق لا يحتاج حساب Meta، لكنه غير رسمي، وقد يقيّد واتساب الرقم أو يحظره. استخدم رقما ثانويا إن أمكن.

1. افتح `http://127.0.0.1:3000/setup`، ومن قسم «واتساب» فعّل «فهمت الخطر وأريد ربط الرقم» ثم اضغط «ربط واتساب برمز QR».
2. في هاتفك: واتساب، ثم الأجهزة المرتبطة، ثم ربط جهاز، وامسح الرمز.
3. يعود الربط تلقائيا عند كل تشغيل، ولإلغائه اضغط «إلغاء الربط» وأزل الجهاز من هاتفك أيضا.

| الإعداد الاختياري | المعنى |
|---|---|
| `LAYANX_WHATSAPP_OWNER_IDS` | أرقام تستطيع إعطاء الأوامر، غير الرقم المربوط |
| `LAYANX_WHATSAPP_STAFF_IDS` | أرقام الموظفين |
| `LAYANX_WHATSAPP_QR_ALLOWED` | أرقام يجوز لـ LayanX أن يبدأ مراسلتها |
| `LAYANX_WHATSAPP_QR_ANSWER_CUSTOMERS` | اجعلها `true` فقط إذا كان الرقم مخصصا لخدمة العملاء |
| `LAYANX_WHATSAPP_DEFAULT_METHOD` | `cloud` أو `qr`، الطريق الافتراضي عند عدم وجود سابق |
| `LAYANX_WHATSAPP_QR` | `off` يمنع عودة الربط عند التشغيل |

**القواعد:** يصل الرد من الطريق الذي وصلت منه الرسالة. ولا يرد LayanX افتراضيا إلا عليك وعلى الموظفين، ولا يبدأ مراسلة أحد لم يكتب أولا إلا إذا كان رقمه في القائمة، ويرسل 60 رسالة في الساعة كحد أقصى.

**الاختبار:** من الهاتف المربوط افتح محادثتك مع نفسك واكتب «اعرض ما فعلته اليوم». يجب أن يصل الرد في المحادثة نفسها مرة واحدة. ثم اطلب من صديق أن يراسلك، ويجب ألا يرد LayanX عليه.

### تيليجرام

| الاسم | القيمة |
|---|---|
| `LAYANX_TELEGRAM_ENABLED` | `true` |
| `LAYANX_TELEGRAM_BOT_TOKEN` | من BotFather |
| `LAYANX_TELEGRAM_OWNER_IDS` | معرفك الرقمي |

**الاختبار:** أرسل رسالة إلى البوت.

### المتجر

| المنصة | الأسماء | عنوان المتجر الذي تعطيه لـ LayanX |
|---|---|---|
| WooCommerce | `LAYANX_WOOCOMMERCE_URL` و `LAYANX_WOOCOMMERCE_CONSUMER_KEY` و `LAYANX_WOOCOMMERCE_CONSUMER_SECRET` | `https://متجرك` (يُكمل LayanX المسار `/wp-json/wc/v3`) |
| Shopify | `LAYANX_SHOPIFY_ACCESS_TOKEN` | `https://متجرك.myshopify.com/admin/api/<الإصدار>` |

**WooCommerce خطوة بخطوة:**

1. في متجرك: WooCommerce ← الإعدادات ← متقدم ← REST API ← إضافة مفتاح، بصلاحية **قراءة** فقط أولاً.
2. في لوحة LayanX (الإعداد ← الأسرار) أضف `LAYANX_WOOCOMMERCE_URL` (عنوان متجرك بـ https، مثل `https://متجرك.com`) والمفتاحين. تُرسل المفاتيح في ترويسة مشفرة، ولا تُكتب في العنوان أبداً.
3. اسأل: «كم طلب جاني اليوم في متجري؟» وقارن العدد والمبيعات بلوحة WooCommerce. (`GET /v1/store/status` يعرض هل المفاتيح صحيحة وعدد المنتجات والطلبات.)
4. للتعديل (سعر، سعر عرض، مخزون، حالة طلب): أنشئ مفتاحاً بصلاحية قراءة/كتابة، وأضف `LAYANX_WOOCOMMERCE_ALLOW_WRITES` بقيمة `on`. كل تعديل ينتظر موافقتك، ثم يُقرأ المنتج أو الطلب من المتجر بعد التعديل للتأكد.
5. لا يلغي LayanX الطلبات ولا يسترجع مبالغها أبداً: هذا يحرك مال العميل، فتفعله أنت.

**الاختبار:** لا تعطِ صلاحية الكتابة قبل أن تطابق أرقام التقرير لوحة المتجر.

**الشحن والفواتير:**
- **شركات الشحن وأسعارها:** تُضاف من مسار `/v1/shipping/carrier`، أو اطلبها من LayanX.
- **«جهّز شحنات طلبات المتجر»:** ينشئ مسودات للطلبات التي تنتظر الشحن، ويذكر ما لم يستطع ولماذا.
- **«اطبع فاتورة الطلب 1041»:** يكتب فاتورة PDF. أضف `LAYANX_SELLER_NAME` لتظهر باسم متجرك، و`LAYANX_SELLER_VAT` إن كان لك رقم ضريبي لتصير فاتورة ضريبية مبسطة مع QR.
- **«الطلبات اللي وصلت اقفلها في المتجر»:** يجعلها «مكتمل» بعد موافقتك.

| الخدمة | الأسماء |
|---|---|
| Yahoo | `YAHOO_EMAIL` و `YAHOO_APP_PASSWORD` (كلمة مرور تطبيق، وليست كلمة الحساب) |
| Google | `GOOGLE_CLIENT_ID` و `GOOGLE_CLIENT_SECRET` و `GOOGLE_REFRESH_TOKEN` |

**الاختبار:** اطلب قائمة آخر الرسائل قبل تجربة أي إرسال.

### MetaTrader 5 (حساب تجريبي فقط)

**قبل الربط:** جسر MT5 يحتاج حزمة Python باسم `MetaTrader5`. منذ الإصدار 5.0.6231 تدعم Python 3.14، فيكفي `python -m pip install MetaTrader5` (ثُبّتت على جهاز المالك في 2026-11-11 مع numpy، والقراءة من الطرفية نجحت). `LAYANX_PYTHON` لازم فقط إن أردت نسخة Python غير الافتراضية. **تنبيه:** الطرفية كانت مسجّلة على حساب حقيقي (`CFI2-Real`) وزر Algo Trading مفعّل؛ قبل الضغط على «اتصل» سجّل الدخول بحساب تجريبي. التداول الحي يبقى معطلاً حتى موافقة منفصلة.

الطريقة الأبسط بعد ذلك: افتح MT5 وسجل الدخول إلى الحساب التجريبي، فيستخدمه LayanX دون أي كلمة مرور. وللدخول الآلي أدخل:

`LAYANX_MT5_LOGIN` و `LAYANX_MT5_PASSWORD` و `LAYANX_MT5_SERVER` و `LAYANX_MT5_TERMINAL_PATH`.

اترك `MT5_ALLOW_REAL_ACCOUNT` على `false`. لن يرسل LayanX أوامر إلا إذا فعلت `MT5_LIVE_TRADING_ENABLED` و `MT5_AUTO_SCALPING_ENABLED`.

**الاختبار:** افتح صفحة التداول في لوحة التحكم، وتأكد أن رقم الحساب ونوعه Demo صحيحان قبل تفعيل أي شيء.

### Binance (الشبكة التجريبية فقط)

أنشئ المفاتيح من `testnet.binance.vision`، ثم أدخل بهذا الترتيب:

| الاسم | القيمة |
|---|---|
| `BINANCE_BASE_URL` | `https://testnet.binance.vision` |
| `BINANCE_API_KEY` و `BINANCE_API_SECRET` | مفاتيح الشبكة التجريبية |
| `BINANCE_MAX_ORDER_NOTIONAL` | حد صغير، مثل `50` |

لتمكين الأوامر على الشبكة التجريبية أضف `BINANCE_LIVE_TRADING_ENABLED` بالقيمة `true`. يرفض LayanX أي أمر خارج الشبكة التجريبية ما لم يوجد المفتاح المنفصل `BINANCE_ALLOW_REAL_MONEY`. لا تضع مفاتيح حقيقية. التداول بأموال حقيقية يحتاج قرارا منفصلا منك وضوابط مخاطرة.

### هاتف Samsung

1. نزل `LayanX-Remote-apk` من GitHub Actions، من آخر تشغيل ناجح لـ LayanX Mobile CI. هذا يتطلب رفع الكود أولا.
2. ثبت التطبيق، ثم اربطه برمز QR من `/setup`.

**الاختبار:** اكتب «افتح يوتيوب»، ثم «تذكر أن موعدي الأحد»، ثم «ماذا تذكر عن موعدي». واكتب «ارسل واتساب إلى 05xxxxxxxx: مرحبا»، ويجب أن يفتح واتساب بالرسالة دون إرسالها.

### شركات الشحن

منصة الشحن تعمل الآن يدويا: أضف الشركات وأسعارها، وقارن الأسعار، وأنشئ الشحنات بأرقام تتبع تدخلها أنت. الربط الآلي بشركة معينة يحتاج موصلا لواجهتها، فحدد الشركة التي تعمل معها وحساب الاختبار إن وجد.

**الاختبار:** اكتب لـ LayanX «أضف شركة شحن اسمها تجربة، تخدم جدة، أول كيلو بـ 15 ريالا وكل كيلو بعده بريالين، خلال يومين»، ثم «كم تكلفة شحن 3 كيلو إلى جدة؟». الجواب الصحيح 19 ريالا.

## 4. تطوير LayanX لنفسه

| ما تريده | أين |
|---|---|
| تشغيل تجربة تحسين واحدة | `POST /v1/improvement/run` |
| التعلم اليومي وتجربة التحسين | يعملان تلقائيا كل ليلة الساعة `03:00` إذا كان الجهاز خاليا. غيّر الوقت بـ `LAYANX_IMPROVE_TIME`، أو أوقفهما بالقيمة `off` |
| تشغيل التعلم الآن | `POST /v1/improvement/learn` |
| ما تعلمه، وما أبقاه أو أسقطه ولماذا، وما ينتظر موافقتك | `GET /v1/improvement/learning` (قائمة `heldForOwner`) |
| المقارنة مع برنامج ثانٍ | `LAYANX_TWIN_CHECK`: يعمل افتراضياً؛ `off` لإيقافه. يكتب النموذج برنامجاً ثانياً مستقلاً ويُشغَّلان على عشرات المدخلات، وأي اختلاف تؤكده قراءة مستقلة يصبح اختباراً |
| إعادة المحاولة عند انتهاء المهلة | `LAYANX_PATIENT_RETRY`: يعمل افتراضياً (مرة واحدة بنفس النموذج بمهلة أطول، 300 ثانية على الأقل)؛ `off` لإيقافه؛ `LAYANX_PATIENT_TIMEOUT_MS` لتحديد المهلة |
| البحث قبل المهمة | `LAYANX_TASK_RESEARCH`: `local` (الافتراضي: الأدلة والدروس المحفوظة فقط، لأن القياس لم يُظهر فائدة للبحث على الإنترنت)، `on` (بحث على الإنترنت بعد أول محاولة فاشلة)، `off` |
| رؤية ما بقي وما رُفض ولماذا | `GET /v1/improvement` |
| طلب دمج مستودع أو حزمة | `POST /v1/intake` بإصدار محدد، ويفحصه دون تشغيله |
| قبول أو رفض ما فُحص | `POST /v1/intake/<id>/decide` |

لا يبقى أي تغيير في الإعدادات إلا إذا تحسن القياس المستقل مرتين. ولا تستطيع هذه الدورة تغيير الثقة أو الموافقات أو الأسرار أو الحسابات الحقيقية، ولا يمكن لوكيل قبول كود خارجي.

### كيف يتعلم كل يوم

- يختار مجالات من الأخطاء التي واجهها، ومن مواضيع طلباتك، ومن قائمة تغطي كل المجالات بالتناوب. لا يرسل إلى الإنترنت إلا أسماء مجالات عامة، ولا يرسل أي اسم أو رقم أو مسار من عملك.
- يبحث في GitHub عن مهارات نصية بترخيص مفتوح، وفي مستودعات نشطة لها نجوم كافية. يقرأ النص فقط عند نسخة محددة، ولا يشغّل أي كود.
- إذا لم يجد مهارة مناسبة، يبحث في الويب ويكتب "أفضل طريقة" بنفسه.
- يقيس كل مهارة: مشاريع بدونها ثم معها. يبقيها فقط إذا لم تُنقص النتائج، ويسقط ما يضر (في قياس حقيقي أسقط دليلا خفض النتائج من 2 من 2 إلى 0).
- المهارات التي تأتي مع سكربتات، أو تطلب تثبيت شيء، أو تخص المال، لا تُستخدم أبدا قبل موافقتك.
- البحث قبل المهمة يُستخدم عند إصلاح المحاولة الفاشلة، لا في المحاولة الأولى. سبب ذلك القياس: إعطاؤه من البداية أربك النماذج المحلية الصغيرة.

## 5. معرفة الجهاز وما يناسبه

عند كل تشغيل يفحص LayanX المعالج والرامات وكرت الشاشة والقرص، ثم يقرر:

- أي نموذج يبني، وأي نموذج يراجع، وأيها للرد السريع والصور والبحث في الذاكرة.
- ما يُستبعد لأنه أكبر من ذاكرة الجهاز أو لا يتسع له القرص (يترك 15 GB فارغة دائما).
- مدة الانتظار وعدد النماذج التي تعمل معا.

إذا تغيّر الجهاز (رامات أو كرت جديد) يلاحظ ذلك ويعيد الخطة، ثم تُقاس النماذج الجديدة قبل اعتمادها. النموذج الأقوى نظريا يدخل "تجربة" فقط، ولا يحل محل النموذج المقاس إلا إذا نجح مثله أو أفضل.

| ما تريده | أين |
|---|---|
| رؤية الخطة لجهازك | `npm run doctor`، أو `GET /v1/hardware` |
| إعادة الفحص الآن | `POST /v1/hardware/check` |
| الموافقة على تحميل نماذج مقترحة | `POST /v1/hardware/approve` مع `{"models":["اسم النموذج"]}` |
| طريقة التحميل | `LAYANX_MODEL_PULL`: `ask` (الافتراضي، لا يحمّل إلا ما وافقت عليه)، `auto` (يحمّل الخطة كلها)، `off` (لا يحمّل شيئا) |

التحميل يتم فقط من خدمة Ollama المحلية. بعض النماذج حجمها 15 إلى 20 GB.

## 6. الصوت المحلي وObscura وتطبيق الجوال

**الصوت (مثبت على هذا الجهاز منذ 2026-11-13):** Whisper للتعرف على الكلام (على كرت الشاشة) وPiper للنطق بالعربية والإنجليزية. يشغّلهما LayanX تلقائياً على المنفذين 8178 و8179، والصوت لا يخرج من الجهاز.
- للتجربة: افتح صفحة المساعد، اضغط زر الميكروفون، وقل جملة بالعربية. يجب أن يظهر نصك، ثم يُقرأ الرد بصوت Piper.
- لإعادة التثبيت على جهاز آخر: `scripts\windows\install-whisper.ps1` ثم `scripts\windows\install-piper.ps1` (يحتاج Python 3.10 إلى 3.13).

**Obscura:** محرك متصفح خفيف بجانب Edge/Chrome. الأداة `browser.render` تستخدمه أولاً لقراءة الصفحات التي لا يظهر محتواها إلا بعد تشغيل JavaScript، وتعود إلى Edge/Chrome عند فشله.
- التثبيت: `scripts\windows\install-obscura.ps1` (النسخة v0.2.6 مثبتة بالتحقق من SHA-256).
- `LAYANX_BROWSER_ENGINE`: `auto` (الافتراضي، Obscura ثم Chromium) أو `chromium` (أسرع على هذا الجهاز) أو `obscura`.
- وضع التخفي في Obscura لا يُستخدم أبداً.
- القياس: `npx tsx scripts/outcome-obscura-acceptance.ts --runs=3`.

**تطبيق الجوال (LayanX Remote):** يُبنى تلقائياً على GitHub عند كل تعديل في `mobile/`، ويُختبر تشغيله على محاكي Android 14.
1. افتح صفحة GitHub Actions للمستودع ← "LayanX Mobile CI" ← آخر تشغيل ناجح على main، ونزّل الملف `LayanX-Remote-apk` (يحتاج تسجيل دخولك إلى GitHub).
2. فك الضغط وانقل `LayanX-Remote.apk` إلى الهاتف، ثم ثبّته (اسمح بالتثبيت من هذا المصدر عند السؤال).
3. على الكمبيوتر: صفحة الإعداد `http://127.0.0.1:3000/setup` ← قسم "الهاتف و VS Code" ← فعّل "السماح للهاتف بالاتصال عبر شبكة Wi-Fi نفسها" ← أعد تشغيل LayanX ← "إنشاء رمز ربط".
4. في التطبيق: الإعدادات ← "ربط بمسح QR" ووجّه الكاميرا إلى المربع. الهاتف والكمبيوتر على نفس شبكة Wi-Fi.
5. فعّل "المتابعة في الخلفية" واسمح بالإشعارات.
6. جرّب: اكتب سؤالاً من الهاتف، ثم اطلب مهمة تحتاج موافقة ووافق عليها بالبصمة من الإشعار.
- إذا سأل Windows عن الجدار الناري عند أول اتصال، اسمح لـ Node.js على "الشبكات الخاصة" فقط.
- من خارج المنزل: "السماح بالتحكم من أي مكان" عبر Tailscale، دون فتح منفذ على الإنترنت.
